# Projet Context

## Règle de développement
Pour chaque demande de développement, suivre ces étapes :
1. **Issue** : Créer une issue avec une priorité définie.
2. **Branche** : Créer une branche dédiée.
4. **Développement** : Effectuer les changements.
5. **Revue** : Ouvrir la MR et demander une relecture puis faire la relecture et merge si c'est bon sinon faire les corrections et ensuite merge.
